# Preflight reuse and automatic task persistence

## Objective

Reuse accepted MDD session preferences without replaying approval authority. Select
Engram automatically for new runs when configured, otherwise preserve complete task
progress and artifacts under `.mdd/tasks/<task-name>/`.

## Problem and rationale

Confirmed material changes currently clear every preflight answer. Fresh intake
also reads only the startup profile, not previously accepted session preferences.
Storage selection adds an unnecessary question, while existing local recovery is
not a complete task artifact store.
